# Verba

## Overview

Verba is a character platform for creating AI companions, assistants, and roleplay bots that feel distinct across text and voice. Users can build personalities, publish shareable character pages, connect bots to Discord, and talk to them through premium voice responses.

ElevenLabs powers Verba's premium voice layer. Characters can answer with high-quality speech, support multilingual output, and use custom cloned voices for a more personal experience.

## Key Features

- Character creation with personality, lore, behavior, and language settings
- Discord bot deployment with text chat, reactions, polls, and voice features
- Premium voice responses powered by ElevenLabs models
- Custom voice cloning workflows for characters
- Public character pages, embeds, and API access for external integrations

## How It Works

Verba combines a web app, backend services, and platform integrations to let users create once and deploy everywhere. A character can live on a shareable web page, inside Discord, and behind an API.

On the voice side, Verba routes premium speech generation through ElevenLabs. Users can select premium voice models, configure speaking behavior, and attach cloned voices so a character sounds consistent across conversations. That makes the same character usable for casual chat, Discord interactions, and voice-first experiences.

## Technologies Used

- ElevenLabs Text-to-Speech for premium voice generation
- ElevenLabs voice cloning for custom character voices
- Next.js and React for the frontend experience
- Node.js and Express for backend APIs and integrations
- Discord integrations for bots, automation, and voice features
