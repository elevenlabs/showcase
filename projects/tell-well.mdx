# Tell-Well

## Overview

Remembering weeks of symptoms and daily habits before a medical appointment can be difficult. Tell-Well makes it easier to record that history through a short conversation, especially when typing is uncomfortable.

Built by Luoqing Shao, Liza Pozhenko and Toan Dang during a 30-hour hackathon, Tell-Well is a mobile-friendly health journal. ElevenLabs transcribes the user's speech and reads prompts aloud, while Gemini organizes reported details into structured health records.

## Key Features

- **Voice check-ins:** Speak naturally, choose from five spoken voices, or switch to typing.
- **Short conversations:** One optional symptom follow-up helps capture details without a long questionnaire.
- **Editable records:** Review symptom and medication details before saving, with original words kept alongside the extracted information.
- **Medication tracking:** Confirmed reports of taking a listed medicine update its daily count.
- **Meals and water:** Record food and glasses of water without additional questions.
- **Wearable context:** WHOOP integration compares readings with the user's recent history.
- **Visit preparation:** Revisit entries in a calendar and create a printable summary of recent check-ins, medications and wearable readings.

## How It Works

The backend creates a single-use ElevenLabs transcription token so the browser can stream microphone audio without receiving the permanent API key. ElevenLabs Scribe Realtime converts speech into text, and the Text to Speech API reads the app's prompts aloud.

Gemini extracts the details the user reported, such as symptom location, pain score and timing. The backend validates the result and limits symptom conversations to one optional follow-up. Symptom and medication entries can be corrected before saving, while food and water entries can log directly.

A separate Python service handles WHOOP authorization and wearable data retrieval. The app also supports saved WHOOP snapshots for demos where the connector is unavailable. Personal comparisons use recent readings rather than a population average.

## Technologies Used

- ElevenLabs Scribe Realtime for speech-to-text
- ElevenLabs Text to Speech for spoken prompts
- Google Gemini for structured information extraction
- HTML, CSS and JavaScript for the interface
- Node.js, TypeScript, Express and Zod for the backend
- Python, FastAPI and httpx for WHOOP integration
- WHOOP API for wearable readings

## Getting Started

[Try the live demo](https://tell-well-demo-production.up.railway.app/auth/) or [watch the demo video](https://www.youtube.com/watch?v=7rvYrlKnK9c). Use fictional information when exploring the prototype.

For local development, install Node.js 24 or newer, then run:

```bash
git clone https://github.com/kimberlieShao/tell-well.git
cd tell-well/backend
npm ci
cp .env.example .env
```

Configure `GEMINI_API_KEY`, `GEMINI_MODEL` and `ELEVENLABS_API_KEY` in the local `.env` file, and set `EXTRACTION_MODE=gemini`. Choose a Gemini model available to your API project. For an initial run without a WHOOP connector, add `WEARABLE_MODE=demo` to use labeled example wearable readings. Keep API keys out of source control. Then start the app:

```bash
npm start
```

Open `http://127.0.0.1:3001/app`. Live WHOOP integration requires its separate service and configuration, with `WEARABLE_MODE=whoop`.
