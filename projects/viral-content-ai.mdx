# Viral Content AI

## Overview

Viral Content AI transforms long-form videos into short-form viral clips and automatically dubs them into multiple languages using **ElevenLabs** AI audio technology.

It enables creators to scale their content globally with minimal manual effort.

## Key Features

- AI-powered viral clip detection
- Automatic titles, captions, and hashtags
- Multi-language AI dubbing with natural voices
- Studio-quality voice synthesis
- Optimized for Shorts, Reels, and TikTok

## How It Works

1. Analyze long-form video to detect high-retention moments
2. Generate scripts for selected clips
3. Translate content into multiple languages
4. Generate dubbed audio using ElevenLabs API
5. Export publish-ready short-form videos

## Technologies Used

- ElevenLabs API (Text-to-Speech for language dubbing)
- Python & FastAPI
- Video processing pipeline
- AI/ML content analysis
