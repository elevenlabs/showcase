# koedesk

## Overview

koedesk is a voice dictation app for **macOS, Windows, iOS, and Android**. On desktop, hold a hotkey, speak, and your words appear at the cursor — in any application. On mobile, it ships as a keyboard: an iOS keyboard extension and an Android IME, so you can dictate into any app. Every platform uses **ElevenLabs Scribe v2** as its speech-to-text engine, fixed server-side, in 36 languages.

koedesk is not just a transcription tool. It is a bet on how we give context to computers. As AI becomes a collaborator rather than just a tool, the amount of context we need to convey has exploded. The keyboard alone is no longer enough. Speaking is now a genuine alternative to typing — and Scribe v2 is accurate enough that koedesk sends you its raw output: no LLM post-processing layer, no cleanup pass.

## Key Features

- **Push-to-talk on desktop**: Hold a key (Fn on macOS, Right Alt on Windows — configurable), speak, release. Text lands at your cursor with no manual copy and paste
- **A keyboard on mobile**: iOS keyboard extension (with Live Activity) and Android IME — tap to start, tap to stop, dictate into any app
- **One engine everywhere**: Scribe v2 on every platform, enforced server-side. The free tier (5 minutes a day, no card required) runs the exact same engine — only the quota differs
- **36 languages**: STT languages and UI locales are deliberately the same 36-language set
- **Personal dictionary, synced**: Register your names and jargon once; entries sync across all your devices and are passed to Scribe v2 as key terms to improve recognition
- **Clean output by default**: Filler words and false starts are removed (Scribe v2's verbatim filtering), and punctuation comes out natural — straight from the model
- **Works where you type**: Any text field in any app, with secure fields (passwords and the like) deliberately excluded
- **Private by design**: koedesk's own servers never store your audio — it is processed in memory and passed straight to the ElevenLabs API
- **Lightweight**: Desktop app built with Rust and Tauri on the OS native WebView — no bundled Chromium

## We benchmarked the engines — in the open

To choose koedesk's engine honestly, we built a public STT benchmark: **13 engines × 12 languages, 28,400 audio samples**, with a pre-registered methodology. The full dataset is published on Hugging Face and the live leaderboard is at [koedesk.app/benchmark](https://koedesk.app/benchmark). Scribe v2's consistently top-tier multilingual accuracy — including Japanese, our home market — is why it is the engine behind koedesk.

## Built for every language, not just English

Most voice-to-text tools are built in the US, optimized for English. Quality drops sharply for other languages, and breaks down when languages mix — Japanese with English technical terms, Vietnamese with code snippets. The lead developer of koedesk is Japanese, working from Vietnam; that firsthand experience shaped every design decision, starting with the choice of Scribe v2.

## How It Works

1. Hold the hotkey (desktop) or tap the mic key (mobile) and speak
2. Audio is captured locally; a local VAD skips silence so nothing empty is sent
3. On release, audio goes to **ElevenLabs Scribe v2** via the Speech-to-Text API — with your dictionary entries attached as key terms
4. The transcription is inserted at your cursor; Esc cancels a desktop recording mid-way

No intermediate LLM step. As Scribe improves, koedesk improves — with no layers of complexity in between.

## Technologies Used

- **ElevenLabs Scribe v2** — Speech-to-text engine on all platforms (Speech-to-Text API)
- **Rust + Tauri v2** — Desktop apps for macOS and Windows, tuned for minimal latency
- **Swift / Kotlin** — iOS keyboard extension with Live Activity; Android IME
- **Cloudflare Workers + D1** — API proxy, authentication, usage tracking, dictionary sync
