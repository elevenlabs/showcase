# An answer is waiting. A guess is not enough.

HarborVoice is an independent, MIT-licensed engineering case study: how should a multilingual voice assistant behave when its answer could affect an operational decision?

Nora helps with a fictional logistics terminal. She retrieves a shipment by exact reference, explains the recorded status and prepares requests for human review. A customs hold remains a hold. A pending escalation remains a proposal. No real terminal systems or customer records are connected.

## Specific ElevenLabs integrations

- **ElevenAgents:** versioned Nora configuration, authenticated voice sessions, shipment lookup and human-review tools, four indexed knowledge documents and English/Dutch/French/German scenarios.
- **ElevenAPI:** v4 narration, streaming speech, realtime and batch Scribe, speaker diarization, forced alignment, voice processing and an original Music v2.5 score.
- **ElevenCreative:** editable commercial, localization, learning and briefing Flows; genuine French dubbing; a native Studio caption project. Final video composition is local and explicitly identified.
- **Developer workflow:** the official SDK, CLI and MCP are used for supported operations. A resource registry and reviewed-hash reconciler detect drift rather than silently overwriting remote edits.

## Architecture and boundaries

The React interface calls a server-side gateway. Provider credentials stay on the server. Tools validate references and return structured fictional records. Consequential business actions require human review. The visitor agent is separate, read-only and provider-limited; public playback uses recorded outputs. A filesystem Credit Governor reserves estimated costs, preserves failed holds and reconciles account-wide observations. It is not distributed multi-user billing protection.

## Measured results

Historical v2.0 evidence records **59 software tests**. Its first native agent suite passed **50 of 52 scenarios**. After prompt and fixture corrections, **10 targeted regression scenarios passed**; a complete rerun of the final configuration is not claimed. These are synthetic provider simulations, not real-customer success rates. Machine-readable reports, failures, configurations and execution limitations are versioned in the repository.

## Reproduce safely

```bash
git clone https://github.com/phlppgdfry/harborvoice-ai.git
cd harborvoice-ai
npm ci
npm run check
npm run dev
```

The default text demonstration uses synthetic business data. Read the README before configuring ElevenLabs credentials. Paid generation and native agent provisioning are separate, explicit operations. Media provenance, capability coverage, native links and the independent-project disclaimer are documented under `docs/elite`.

## Inspect evaluation evidence

AgentOps Kit inspects redacted configuration, compares drift and imports existing native test receipts without dispatching runs. Optional structured contracts check exact tool arguments and facts. AgentProof is a static explorer of 110 scripted scenarios and twelve multilingual adversarial observations. Fixture pass counts measure the validator, not ElevenLabs model reliability. There is no real-user adoption claim. The separately deployed PostgreSQL voice runtime remains under explicit operational acceptance gates; recorded media and the static demo are the unrestricted review surfaces.
