# Quiet Protocol

## Overview

Quiet Protocol is a multiplayer detective-style simulation game where players interact with AI-powered NPCs inside a real-time pixel world. Every NPC is controlled by dynamic agent logic, enabling contextual conversations, memory, and role-driven behavior.  
The game integrates AI-orchestrated interactions with blockchain-verified reward mechanics, creating a persistent, incentive-driven narrative world.

## Key Features

- AI-Powered Agents: NPCs with stateful personalities, contextual awareness, and dynamic conversation flow.
- Multiplayer Pixel World: Built using Phaser, enabling exploration, missions, and real-time player interactions.
- On-Chain Reward System: Smart contract-based token payouts validated and triggered by backend logic.
- Anti-Spam Validation: Secure interaction tracking and backend-enforced eligibility rules.
- Persistent Simulation: Conversations influence missions, trust levels, and rewards.

## How It Works

Quiet Protocol connects three major systems:

1. Phaser Frontend (game1)  
   Players explore a pixel world and interact with NPCs using a real-time dialogue UI.

2. FastAPI Backend (agents_backend)  
   Handles agent orchestration, state management, reward eligibility verification, and dialogue generation.

3. Quai Smart Contract (game_contract)  
   Executes token payouts once the backend validates player interactions.

### Interaction Flow

Player (Browser)  
↓  
Phaser Frontend (game1)  
↓  
FastAPI Backend (agents_backend)  
↓  
AI Agent Orchestration + Reward Logic  
↓  
Quai Smart Contract (game_contract)
