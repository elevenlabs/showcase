# Server Rush

## Overview

Server Rush is a mobile game where you build and manage your own data center — placing server racks, keeping them powered and cooled, and firefighting a constant stream of incidents before they take your servers offline. Inspired by the charm of Hay Day and Stardew Valley, it swaps crops and barns for server racks and cooling units.

An AI guide character named **Chip** roams your data center. His dialogue is generated by Mistral AI based on live game context, and his voice is brought to life by **ElevenLabs Text-to-Speech**, giving him a distinct spoken personality. Chip warns you about incidents, celebrates milestones, and answers questions when you tap him — all spoken aloud, not just text on screen.

## Key Features

- **ElevenLabs TTS voice for Chip**: Every line of AI-generated dialogue is spoken aloud using ElevenLabs, making the guide feel like a real companion
- **Real-time game context**: Chip's dialogue reflects your current money, incidents, equipment, and resource status
- **Graceful fallback**: Game works perfectly without API connectivity using local dialogue strings
- **Procedural sound effects**: 13 synthesized sounds via AVAudioEngine that coexist with ElevenLabs audio using shared audio session

## How It Works

1. **Mistral AI** generates contextual dialogue based on a rich game state snapshot (money, revenue, equipment count, active incidents, resource percentages)
2. The generated text is sent to the **ElevenLabs TTS API**, which returns spoken audio
3. Audio plays through `AVAudioPlayer` using a shared `AVAudioSession` configured with `.mixWithOthers`, so Chip's voice layers cleanly over the game's procedural sound effects
4. Chip's speech bubble displays the text with a typewriter animation while the voice plays

The integration uses `ElevenLabsService` — a singleton that manages the TTS connection, handles rate limiting, and provides automatic fallback if the API is unavailable.

## Technologies Used

- **ElevenLabs API** — Text-to-Speech for Chip's voice
- **Mistral AI API** — Dialogue generation with game context
- **SpriteKit** — Isometric game world with programmatic sprites
- **SwiftUI** — All UI overlays (HUD, menus, modals)
- **AVAudioEngine** — Procedural sound synthesis (13 sounds, no asset files)
- **XcodeGen** — Project generation

## Getting Started

```bash
git clone https://github.com/Mukund2/ServerRush.git
cd ServerRush
xcodegen generate
open ServerRush.xcodeproj
```

Set your ElevenLabs API key and Mistral API key in the app to enable Chip's voice and dialogue. The game is fully playable without API keys — Chip simply uses fallback dialogue.
